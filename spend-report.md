# Case study spend report

**Report date:** 2026-08-01  
**Scope:** Paid subscriptions used solely to test five AI-video competitors for the Vivideo competitor-analysis case study.

## Summary

Five short-term monthly subscriptions were purchased to create and evaluate the same five benchmark videos across the selected products: a one-prompt educational short, product advertisement, text-to-video clip, image-to-video clip, and avatar explainer. The subscriptions were necessary to access paid generation credits, remove free-tier constraints where applicable, and document each product's workflow and output for the written comparison.

| Metric | Amount |

| Total subscription price | **US$118.00** |
| Actual TRY charge documented for InVideo AI | TRY 985.87 |
| Actual TRY charge documented for Runway | TRY 886.84 |

The TRY amounts are kept separate because they are checkout charges shown at the applicable exchange rate (and, for Runway, include VAT). They should not be added to the US$ total.
