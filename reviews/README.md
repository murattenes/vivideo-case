# User-review evidence

These files summarize direct user-review observations captured on 2026-08-01.

## Rules

- Use direct user reviews as user voice. Treat platform-generated summaries and editorial articles as secondary context only.
- Keep both the source-page URL and screenshot before citing a review in the presentation.
- Keep excerpts short and paraphrase when possible.
- Label App Store feedback as mobile-app feedback and do not silently generalize it to the web product.
- Describe serious accusations as reviewer claims, not verified facts.
